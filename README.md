# 猜碰撞 · 世界模型演示

在线体验：<https://zhougefei.github.io/world-model-investor-demo/>

世界模型的一个子问题：看一段小球运动的前 32 帧，判断接下来 16 帧里小球会不会撞上方块。
两张卡片并排给出两个模型的判断——我们搜出来的结构、按同规模复现的 V-JEPA 式对照——只显示会撞 / 不会撞，
然后用物理引擎播放后 16 帧揭晓。

- **随机测试集**：从 1000 题独立测试集里按随机种子 20261015 抽出的 20 题，出题区里全部列出、可任选。
  两个模型的判断是离线跑批的结果，浏览器里不运行模型。
- **三维视频**：同一种结构搬到 CLEVRER 三维渲染视频上、重新训练后的结果。
- 屏幕上的未来画面由物理引擎生成，不是模型画的。所有数字的含义、样本量和来源见页面里的「附录」（按 A）。
- `testset.html`：测试集 1000 题逐题的真实结果和两个模型的判断；`selfcheck.html`：网页物理引擎与数据生成器的逐帧一致性自检。

纯静态网页，无外部依赖，键盘 `1` `2` 切板块，`空格` 下一步。

本仓库由项目源码里的 `tools/build_public_site.py` 生成，请勿手改。
